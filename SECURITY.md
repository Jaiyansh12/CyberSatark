# Security Policy

## Supported Versions

We issue security patches and updates for the following versions of CyberSatark:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x (Latest) | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

As a cybersecurity education and diagnostics platform, **CyberSatark** takes security vulnerabilities extremely seriously.

> [!IMPORTANT]
> **Please do NOT report security vulnerabilities through public GitHub issues.**

### How to Disclose a Vulnerability Privately
If you discover a security vulnerability or exploit in CyberSatark (such as credential leaks, XSS risks, API key exposures, or Auth bypasses):

1. Email your findings to **openthreatlabs@gmail.com** or submit a private security advisory via [GitHub Security Advisories](https://github.com/OpenThreatLabs/CyberSatark/security/advisories/new).
2. Please include:
   - A clear description of the vulnerability.
   - Steps to reproduce or proof-of-concept (PoC).
   - The potential impact of the vulnerability.

### Our Response Commitment
- **Acknowledgement**: We will acknowledge your report within 48 hours.
- **Triage**: We will assess the severity and provide a timeline for resolution within 5 business days.
- **Fix & Disclosure**: Once a patch is developed and verified, we will publish an update and credit your research (unless you prefer to remain anonymous).

Thank you for helping keep CyberSatark and the OpenThreatLabs ecosystem secure! 🛡️
